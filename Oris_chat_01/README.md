
Сетевой чат на PyQt6

Самостоятельная работа по дисциплине ОРИС.

Описание

Сетевой чат на Python с использованием PyQt6,
TCP-сокетов и потоков.

Выполненные задания

1. Отображение имени отправителя.
2. Защита от пустых сообщений.
3. Отправка сообщения по Enter.
4. Обработка сообщений типов chat и system.

Технологии

- Python
- PyQt6
- TCP sockets
- QThread
- JSON

Установка


python -m pip install -r requirements.txt


Запуск

Сначала запустить сервер:

python server.py

Затем в двух отдельных терминалах запустить клиентов:

python client.py

Проверка

В двух окнах ввести разные имена и отправить сообщения.

Проверить:
- отображение имени отправителя;
- блокировку пустых сообщений;
- отправку по Enter;
- системное сообщение о подключении.
