Cервер задач

Небольшая программа для работы со списком задач через сервер и клиент.
Как запустить
1. Запустите сервер: python3 server.py
2. Откройте второй терминал и запустите клиента: python3 client.py
3. Для подключения другого пользователя запустите ещё одного клиента.
Команды
* /add <текст> — добавить задачу.
* /list — вывести список задач.
* /done <номер> — отметить задачу как выполненную.
* /delete <номер> — удалить задачу.
* /help — показать список команд.
* /quit — завершить работу клиента.
Как работает программа
Сервер принимает подключения и обрабатывает каждого клиента в отдельном потоке. Список задач хранится на сервере и доступен подключённым клиентам.
Для безопасной работы с общим списком используется threading.Lock(). После перезапуска сервера список задач очищается.
